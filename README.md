# Organization profile for swack-tools

The public organization profile lives in [profile/README.md](profile/README.md)
and appears on [github.com/swack-tools](https://github.com/swack-tools).

Edit that file to update the profile. The banner source is
[profile/assets/banner.svg](profile/assets/banner.svg); the organization avatar
is [profile/assets/avatar.svg](profile/assets/avatar.svg), exported to
[avatar.png](profile/assets/avatar.png) for upload in Organization settings.

This repository also holds the organization's default community health files,
which GitHub applies to any `swack-tools` repository that does not ship its own:

- [SECURITY.md](SECURITY.md): how to report a vulnerability.
- [CONTRIBUTING.md](CONTRIBUTING.md): how to file issues and open pull requests.

Keep project descriptions grounded in their public documentation. Check links
and preview the profile on GitHub after publishing changes.
